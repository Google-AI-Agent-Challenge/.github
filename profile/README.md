# 💄 TONES 
> **우연최연우** 팀과 함께하는 H&B 입점 뷰티 브랜드를 위한 AI 대화형 리뷰 관제 솔루션

## 📖 프로젝트 소개
하루 수만 건씩 쌓이는 고객 리뷰,  
아직도 실무자가 직접 읽고 계신가요?

**TONES**는 H&B 스토어 입점 뷰티 브랜드사를 위한  
B2B 특화 AI 리뷰 감성 분석 대시보드입니다.

리뷰 원문, 별점, 제품 정보를 기반으로 고객 VOC를 분석하고,  
감성 분류·핵심 키워드·이슈 유형·변동 추이를 한 화면에서 시각화합니다.

또한 단순 키워드 검색이 아닌,  
“수분감은 좋지만 트러블이 발생했다”와 같은 양가감정 리뷰까지 분석할 수 있도록  
화장품 도메인 특화 감성 분석 구조를 적용했습니다.

---

## 🎯 문제 정의

기존 H&B 입점 브랜드사의 리뷰 모니터링 방식은 대량의 비정형 리뷰 데이터를 사람이 직접 확인하거나, 단순 키워드 검색에 의존하는 구조가 대부분입니다. 이로 인해 부정 VOC를 빠르게 파악하기 어렵고, 제품 이슈에 대한 대응 시점이 늦어지는 문제가 발생합니다.

| 기존 방식 | 한계 |
| :--- | :--- |
| 담당자가 리뷰를 직접 확인 | 수작업 시간이 과도하게 발생 |
| 단순 키워드 검색 | 문맥 및 양가감정 분석 어려움 |
| 엑셀 중심 데이터 관리 | 실시간 추이 파악 한계 |
| 부정 VOC 사후 대응 | 트러블·홍조·자극 이슈 조기 감지 어려움 |

**TONES**는 리뷰 데이터를 감성 분석 기반으로 정량화하고 시각화하여,  
브랜드 담당자가 제품 리스크와 VOC 흐름을 보다 효율적으로 분석하고 의사결정에 활용할 수 있도록 지원합니다.

## ✨ 핵심 기능 (Key Features)

### 1. 자연어 명령 기반 동적 대시보드 (Interactive AI UI)
* **기능 소개**
  > 사용자는 복잡한 필터를 직접 조작하지 않고도 자연어로 원하는 분석 결과를 요청할 수 있습니다. 예를 들어 다음과 같은 질문을 입력할 수 있습니다. > “당근 패드 트러블 관련 부정 리뷰 보여줘” > “최근 30일 동안 홍조 이슈가 증가한 제품 알려줘” > “긍정 리뷰가 많은 패드 TOP 5 보여줘” 시스템은 자연어 질문을 분석 조건으로 변환한 뒤, Supabase에 저장된 리뷰 데이터를 기반으로 관련 차트와 리뷰 목록을 동적으로 제공합니다.
* **UI 디자인**
  > 좌측에는 자연어 질의 입력 영역을 배치하고, 우측에는 분석 결과 카드와 차트를 배치했습니다. 사용자는 질문 입력 후 리뷰 수, 감성 비율, 주요 키워드, 대표 리뷰를 한 화면에서 확인할 수 있습니다.
  
### 2. 화장품 도메인 특화 감성 분석 (ABSA)
* **기능 소개**
  > TONES는 단순히 리뷰를 긍정과 부정으로만 나누지 않습니다. 리뷰 원문과 별점을 함께 고려하여 다음 정보를 분석합니다. 감성 분류: positive, neutral, negative | 감성 점수: sentiment_score | 핵심 키워드: 트러블, 홍조, 보습, 진정, 끈적임 등 | 이슈 유형: 피부 트러블, 홍조/붉어짐, 향 불만, 사용감 불만, 보습력 부족 등 | AI 요약: 브랜드 담당자를 위한 한 문장 요약. 예를 들어 “홍조가 생겼다”는 부정 VOC로 분류하지만, “홍조가 진정됐다”는 긍정 효과로 분류하도록 문맥을 반영했습니다.
* **UI 디자인**
  > 분석 결과는 태그와 카드 형태로 표현됩니다. 감성은 색상 뱃지로 구분하고, 키워드와 이슈 유형은 태그 형태로 표시하여 리뷰 원문과 분석 결과를 빠르게 비교할 수 있게 했습니다.

### 3. 제품별 VOC 관제 및 차트 시각화
* **기능 소개**
  > TONES는 리뷰 데이터를 제품 단위로 분석합니다. 현재 데모 데이터는 스킨푸드 11종(당근 패드, 복숭아 패드, 감자 패드, 도토리 패드, 미나리 패드, 라이스 패드, 핑크자몽 패드, 블루 캐모마일 패드, 아스파라거스 패드, 샤인머스캣 패드, 레몬그라스 패드) 패드 제품을 기준으로 구성했습니다.  각 제품별 리뷰 수, 감성 분포, 주요 부정 이슈, 키워드 빈도 등을 비교할 수 있습니다.
* **UI 디자인**
  > Recharts 기반 차트를 활용해 전체 감성 비율, 제품별 부정 리뷰 수, 주요 키워드 TOP 5, 이슈 유형별 분포, 기간별 부정 리뷰 추이를 시각화합니다. 

### 4. 신규 리뷰 AI 분석 및 Supabase 저장
* **기능 소개**
  > 사용자가 신규 리뷰를 입력하면 Vertex AI 기반 감성 분석 모듈이 리뷰 내용을 분석하고, 결과를 Supabase `reviews` 테이블에 저장합니다. 저장되는 주요 데이터는 제품 ID, 리뷰 원문, 별점, 감성 분류(긍정·중립·부정), 감성 점수, 핵심 키워드, VOC 이슈 유형, AI 요약 문장 등으로 구성됩니다.
* **UI 디자인**
  > 리뷰 입력 영역은 제품 선택, 피부 타입, 별점, 리뷰 원문 입력 필드로 구성했습니다. 분석 및 저장 버튼 클릭 시 결과가 자동 반영되며, 대시보드 차트와 리뷰 테이블이 함께 갱신되도록 설계했습니다.

### 5. 실무형 리포트 및 원문 리뷰 검증
* **기능 소개**
  > 자연어 질의 결과를 기반으로 총 리뷰 수, 감성 비율, 주요 키워드, 대표 VOC 이슈, 대표 리뷰, AI 요약 문장 등을 포함한 실무형 리포트를 제공합니다. 단순 차트 시각화를 넘어 실제 브랜드 담당자의 회의 및 운영 보고에 활용할 수 있도록 구성했습니다.
* **UI 디자인**
  > AI 요약 카드와 원문 리뷰 테이블을 함께 배치하여, 분석 결과와 실제 리뷰 내용을 동시에 검토할 수 있도록 구성했습니다. 사용자는 요약 정보와 원문 리뷰를 교차 확인하며 VOC 흐름을 빠르게 파악할 수 있습니다.
